📚 How It Works Under the Hood

1. Dynamic Routing

When a user requests http://localhost:3000/:shortUrl, Express matches the path using parameterized routing. The identifier is retrieved via req.params.shortUrl.

2. Request Handling

The POST endpoint /api/shorten reads the long URL from req.body, validates the format, and generates a random alphanumeric string if no custom code is provided.

3. HTTP Redirection

Express issues an HTTP 302 Found header via res.redirect(target), instructing the client's browser to immediately navigate to the target address.
